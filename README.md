# WebSockets and Security

Proiectul reprezintă o aplicație distribuită pe microservicii, destinată gestionării utilizatorilor, a dispozitivelor inteligente de măsurare a energiei electrice și a consumului asociat acestora. Sistemul include și un modul de chat în timp real între utilizatori și administratori, implementat cu WebSocket. Aplicația este compusă dintr-un microserviciu pentru gestionarea utilizatorilor și autentificare, un microserviciu pentru gestionarea dispozitivelor inteligente, un microserviciu pentru comunicarea prin chat, o interfață web frontend dezvoltată în React, un server Nginx pentru reverse proxy și HTTPS, o bază de date MySQL și un fișier Docker Compose pentru rularea unitară a tuturor componentelor. Tehnologiile utilizate sunt Java 17, Spring Boot, ReactJS, WebSocket (Spring Messaging), MySQL, JWT (JSON Web Token), Docker & Docker Compose și Nginx. Funcționalitățile implementate sunt: gestionarea conturilor de utilizatori (CRUD), gestionarea dispozitivelor inteligente (CRUD), asocierea utilizatorilor cu dispozitive multiple, stocarea consumului orar de energie în format `<timestamp, consum>`, autentificare și autorizare cu token JWT, arhitectură modulară pe microservicii independente, comunicare în timp real între utilizatori și administratori prin WebSocket, casetă de chat în interfața frontend, trimitere asincronă a mesajelor cu identificator de utilizator, notificare la citirea mesajelor (seen), indicator de tastare în timp real (typing...), comunicare completă bidirecțională între un utilizator și un administrator. Funcționalitatea în care administratorul poate comunica simultan cu mai mulți utilizatori este în curs de dezvoltare. Pentru rulare locală, este necesar să fie instalate Java 17, Maven, Node.js (v18+), MySQL, iar bazele de date să fie create manual. Se rulează build-ul pentru backend prin `./mvnw clean install` în fiecare microserviciu, apoi build-ul frontendului prin `npm install` și `npm run build`. Pornirea backendului se face cu `./mvnw spring-boot:run` în fiecare serviciu, iar frontendul cu `npm start`. Aplicația poate fi accesată la `http://localhost:3000`. Alternativ, aplicația poate fi rulată complet containerizat cu Docker, folosind comanda `docker-compose up --build`, după instalarea Docker și Docker Compose. În acest mod, aplicația este accesibilă la `https://localhost`. Structura proiectului include directoarele `chat/` pentru microserviciul de chat, `device/` pentru dispozitive, `energy-management/` pentru utilizatori și autentificare, `energy-management-frontend/` pentru frontendul în React, `nginx/` pentru configurarea serverului Nginx și fișierul `docker-compose.yml` pentru orchestrare.
